メリハリベイク Webサイト（デザイン案E）

■ 見かた
1. このフォルダ（ZIPの場合は展開したもの）をパソコンに保存します。
2. 「index.html」をダブルクリックすると、ブラウザでトップページが開きます。
3. メニューページは「menu.html」です（トップのヘッダーからも移動できます）。
※ フォントと地図はインターネットから読み込むため、ネットにつながった状態で開いてください。
※ Googleドライブ上でindex.htmlを開いても、Webページとしては表示されません。必ず一度ダウンロードしてから開いてください。

■ ファイル構成
index.html   … トップページ
menu.html    … メニューページ
style.css    … デザイン（色・フォント・レイアウト）
images/      … 写真（すべてUnsplashの無料の参考写真です）
images/menu/ … メニューページの写真

■ 公開前に差し替えるもの
・[価格] と書かれている箇所
・ロゴ（ヘッダーの「MB」）とキャラクター（トップページ「私たちについて」の丸）
・写真：images フォルダの同じファイル名で上書きすると差し替わります
・価格は2024〜2025年の取材記事に載っていたものです。最新の価格をご確認ください。
